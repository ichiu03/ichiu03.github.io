# Project agents

Specialists for this project (frontend, backend, data, and so on). Add one only after the same
kind of task has come up a couple of times. Delete this README once you have one.

Each agent is a markdown file with frontmatter:

```markdown
---
name: frontend
description: When the orchestrator should use this agent, and what to give it.
tools: Read, Grep, Glob, Bash, Edit, Write
model: inherit
---

Who you are, what you own (directories, layers), what you must not touch, the stack conventions
to follow, and the report format: Result, Evidence, Open questions, Wiki notes.
```
